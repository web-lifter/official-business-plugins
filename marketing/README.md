# Marketing

**30 skills** for branding, SEO and explicit local-tool setup. No package install
runs when a session starts. Read [RUNTIME.md](RUNTIME.md) before any workflow.

Use `seo-status` to inspect readiness and `seo-setup` to review dependencies before
an authorised installation. Persistent environments live outside the plugin tree.
The previous slash command names now resolve to skills, keeping one implementation.

Python helpers need Python 3.11+. Full SEO requirements include the bundled
clustering engine, not a developer-machine file URL. Heavy semantic/advanced
clustering dependencies are optional. Model downloads may still be required after
installing those optional packages. Lighthouse needs an explicitly installed
current compatible Node/Chrome environment; this plugin does not install it.

Prefer authorised connectors in ChatGPT. Local plaintext credential files are a
fallback, not encryption or a secret manager. Never upload real credentials into
this repository or a chat. Paid requests and crawls require user authorisation.
