# Status interpretation

Read the selected venture without modifying it. A missing document means not yet recorded, not that the activity never occurred. Cite each reported count and indicate incomplete coverage. Canvas coverage is `mapped`, `partial` or `unmapped`, not proof of market fit. Infer phase only as a labelled recommendation using [phase-router rules](../phase-router/reference.md). A test requires recorded observations and a concluded status before a learning-card recommendation.
